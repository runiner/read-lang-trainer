# exercise-content Specification

## Purpose

Определяет встроенную базу примеров для чтения, размеченных по уровням сложности, и правила подбора упражнений в сессию.

## Requirements

### Requirement: База примеров размечена по уровням
Система SHALL хранить встроенную базу примеров; каждый пример относится ровно к одному из шести уровней: «гласные», «простые слоги», «слоги», «слова», «фразы», «текст». Каждый пример — текст для чтения вслух (кириллица). Уровень «текст» хранит произведения классических детских текстов, каждое с названием, автором и текстом, разбитым на части разметкой (перенос строки = граница части, пустые строки игнорируются).

#### Scenario: Пример на каждом уровне
- **WHEN** запрашиваются примеры любого из шести уровней
- **THEN** возвращается непустой набор примеров этого уровня

#### Scenario: Произведения уровня «текст»
- **WHEN** запрашивается список произведений уровня «текст»
- **THEN** возвращаются не менее двух произведений, у каждого есть название, автор и как минимум две ненулевые части

### Requirement: Подбор упражнений по уровню
Система SHALL формировать последовательность упражнений сессии только из примеров выбранного уровня сложности. Для уровня «текст» упражнениями являются части одного выбранного произведения в порядке их следования в разметке.

#### Scenario: Сессия уровня «гласные»
- **WHEN** запущена сессия уровня «гласные» размером 8
- **THEN** показаны 8 упражнений, каждый пример состоит из гласных букв уровня

#### Scenario: Сессия уровня «текст»
- **WHEN** запущена сессия уровня «текст» с выбранным произведением
- **THEN** показано столько упражнений, сколько частей в разметке, и они по порядку воссоздают весь текст произведения

### Requirement: Размер сессии больше доступной базы
Если количество запрошенных упражнений превышает число уникальных примеров уровня, система SHALL повторять примеры до нужной длины. Это правило не применяется к уровню «текст»: там размер сессии задаётся разметкой частей одного произведения, а не отбором из множества примеров.

#### Scenario: Недостаточно уникальных примеров
- **WHEN** запрошена сессия из 50 упражнений уровня с 20 уникальными примерами
- **THEN** сессия содержит 50 упражнений, примеры повторяются

#### Scenario: Уровень «текст» без повторов
- **WHEN** сессия уровня «текст» содержит N упражнений
- **THEN** каждое упражнение — следующая часть того же произведения, порядок соответствует разметке
