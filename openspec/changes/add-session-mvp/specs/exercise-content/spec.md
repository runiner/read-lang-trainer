# Spec Delta

## Purpose

Определяет встроенную базу примеров для чтения, размеченных по уровням сложности, и правила подбора упражнений в сессию.

## ADDED Requirements

### Requirement: База примеров размечена по уровням
Система SHALL хранить встроенную базу примеров; каждый пример относится ровно к одному из пяти уровней: «гласные», «простые слоги», «слоги», «слова», «фразы». Каждый пример — текст для чтения вслух (кириллица).

#### Scenario: Пример на каждом уровне
- **WHEN** запрашиваются примеры любого из пяти уровней
- **THEN** возвращается непустой набор примеров этого уровня

### Requirement: Подбор упражнений по уровню
Система SHALL формировать последовательность упражнений сессии только из примеров выбранного уровня сложности.

#### Scenario: Сессия уровня «гласные»
- **WHEN** запущена сессия уровня «гласные» размером 8
- **THEN** показаны 8 упражнений, каждый пример состоит из гласных букв уровня

### Requirement: Размер сессии больше доступной базы
Если количество запрошенных упражнений превышает число уникальных примеров уровня, система SHALL повторять примеры до нужной длины.

#### Scenario: Недостаточно уникальных примеров
- **WHEN** запрошена сессия из 50 упражнений уровня с 20 уникальными примерами
- **THEN** сессия содержит 50 упражнений, примеры повторяются
