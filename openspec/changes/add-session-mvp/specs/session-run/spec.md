# Spec Delta

## Purpose

Определяет поведение прохождения сессии: показ упражнений по одному и управление переходами без проверки произношения ребёнка.

## ADDED Requirements

### Requirement: Показ одного упражнения
Система SHALL показывать одно упражнение за раз: текст примера крупным шрифтом и счётчик прогресса «текущий номер из общего количества».

#### Scenario: Отображение упражнения
- **WHEN** сессия запущена
- **THEN** на экране виден ровно один текст упражнения и позиция вида «1 / 10»

### Requirement: Переход к следующему упражнению
Система SHALL показывать следующее упражнение по нажатию пробела или кнопки «Далее». Проверка правильности прочтения не выполняется — чтение контролирует взрослый.

#### Scenario: Пробел
- **WHEN** во время показа упражнения нажат пробел
- **THEN** сразу отображается следующее упражнение, счётчик увеличен на 1

#### Scenario: Кнопка Далее
- **WHEN** взрослый нажимает кнопку «Далее»
- **THEN** отображается следующее упражнение

### Requirement: Конец сессии
Когда показано последнее упражнение из настроенного количества, система SHALL вместо следующего упражнения показать экран статистики сессии; дальнейшие нажатия «Далее» не создают упражнений сверх настройки.

#### Scenario: Завершение
- **WHEN** ребёнок прочитал упражнение N из N и нажал «Далее»
- **THEN** открыт экран статистики сессии
