# Spec Delta

## Purpose

Определяет поведение прохождения сессии: показ упражнений по одному и управление переходами без проверки произношения ребёнка.

## ADDED Requirements

### Requirement: Показ одного упражнения
Система SHALL показывать одно упражнение за раз: текст примера крупным шрифтом и счётчик прогресса «текущий номер из общего количества».

#### Scenario: Отображение упражнения
- **WHEN** сессия запущена
- **THEN** на экране виден ровно один текст упражнения и позиция вида «1 / 10»

### Requirement: Переход к следующему упражнению
Система SHALL показывать следующее упражнение по нажатию пробела, кнопке «Далее» или тапу по области упражнения. Проверка правильности прочтения не выполняется — чтение контролирует взрослый.

#### Scenario: Пробел
- **WHEN** во время показа упражнения нажат пробел
- **THEN** сразу отображается следующее упражнение, счётчик увеличен на 1

#### Scenario: Кнопка Далее
- **WHEN** взрослый нажимает кнопку «Далее»
- **THEN** отображается следующее упражнение

#### Scenario: Тап по экрану
- **WHEN** на сенсорном устройстве выполнен тап по области упражнения
- **THEN** отображается следующее упражнение (эквивалентно кнопке «Далее»)

### Requirement: Мобильная адаптивность интерфейса
Все экраны приложения SHALL оставаться пригодными для использования на телефоне: без горизонтального прокручивания, с целями нажатия не менее 44×44 CSS-пикселя и читаемым крупным текстом.

#### Scenario: Экран упражнения на узком телефоне
- **WHEN** приложение открыто на экране шириной 360 px
- **THEN** текст упражнения и кнопка «Далее» видны целиком, горизонтальная прокрутка отсутствует

### Requirement: Отметка времени упражнения
Система SHALL фиксировать момент перехода от упражнения к следующему, чтобы по завершении сессии посчитать скорость чтения (см. capability `session-stats`).

#### Scenario: Отметка при переходе
- **WHEN** ребёнок перешёл от упражнения k к упражнению k+1 любым способом (пробел, кнопка, тап)
- **THEN** система сохранила отметку окончания упражнения k

### Requirement: Конец сессии
Когда показано последнее упражнение из настроенного количества, система SHALL вместо следующего упражнения показать экран статистики сессии; дальнейшие нажатия «Далее» не создают упражнений сверх настройки.

#### Scenario: Завершение
- **WHEN** ребёнок прочитал упражнение N из N и нажал «Далее»
- **THEN** открыт экран статистики сессии
