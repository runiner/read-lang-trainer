# Proposal

## Why

Ребёнку 5–7 лет нужен простой тренажёр чтения русских слогов, который взрослый запускает на одно занятие. Сейчас приложения нет вообще; этот change создаёт работающий MVP: полный цикл «настройки → упражнения → статистика» без внешнего бэкенда и без распознавания речи (произношение контролирует взрослый).

## What Changes

- Создаётся запускаемое веб-приложение (Rust → WebAssembly + TypeScript/Vite).
- При старте открывается окно настроек сессии: количество упражнений (размер сессии) и уровень сложности (гласные / простые слоги / слоги / слова / фразы).
- Добавляется встроенная база примеров, размеченная по уровням сложности (константа в crates/core, без UI-редактирования).
- Сессия показывает упражнения по одному; переход к следующему — пробел или кнопка «Далее». Ребёнок читает вслух, приложение не проверяет произношение.
- По достижении заданного количества упражнений показывается экран статистики сессии.
- История завершённых сессий сохраняется в localStorage браузера.

## Capabilities

### New Capabilities

- `session-settings`: окно настроек сессии при старте — выбор размера сессии и уровня сложности, запуск сессии.
- `exercise-content`: база примеров, размеченных по уровням сложности, и генерация последовательности упражнений для сессии.
- `session-run`: показ упражнений по одному, управление переходом (пробел/кнопка), определение конца сессии.
- `session-stats`: экран итоговой статистики сессии и сохранение истории сессий в localStorage.

## Impact

- Новая кодовая база: workspace `crates/core` (чистая Rust-логика: контент, генерация сессий, статистика), `crates/wasm` (wasm-bindgen прослойка), `web/` (Vite + TypeScript UI, localStorage-адаптер).
- Зависимости: wasm-bindgen, web-sys (localStorage), Vite, TypeScript.
- OpenSpec: четыре новых capability-спека в `openspec/specs/` после архивации.
