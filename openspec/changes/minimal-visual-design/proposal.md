# Proposal

## Why

Визуал собран «как получилось»: зелёные кнопки на белом, разбросанные контролы, нет единой системы отступов и состояний. Глазу ребёнка и взрослого на 5–10-минутном занятии нужна спокойная, предсказуемая страница — сдержанный минимализм в духе классических веб-интерфейсов (нейтральная палитра, тонкие границы, чёткая типографика), но со своими цветами под детский контекст. Никаких анимаций: смена экранов мгновенная.

## What Changes

- Вводится дизайн-токены слоя: палитра (нейтральные серые для фона/текста/границ + один тёплый акцент для действий), шкала размеров шрифта и отступов, единые скругления/границы — всё через CSS custom properties.
- Все три экрана (настройки, упражнение, статистика) плюс история и методика переоформляются по токенам: карточная структура окна настроек, спокойный фон, акцентная кнопка «Начать»/«Далее», читаемый контраст.
- Состояния контролов становятся явными: hover/focus-visible/disabled (readonly-поле размера), ошибки-подсказки одним стилем.
- Жёстко фиксируется: без transition/animation; поведение `prefers-reduced-motion` не требуется (анимаций нет).
- Функциональность не меняется: ни одна спека поведения не правится; существующие требования a11y (контраст, цели ≥44px, keyboard focus) остаются нижняя граница — новый стиль обязан их сохранять.

## Capabilities

### New Capabilities

- `ui-presentation`: визуальный язык приложения — палитра, типографика, отступы, состояния контролов, статичность переходов; применим ко всем экранам и не меняет поведение.

### Modified Capabilities

_(нет — изменения чисто косметические, требования session-run/session-settings про размеры и фокус остаются выполненными как есть)_

## Impact

- `web/src/style.css` переписывается на токенах (~116 строк → сопоставимо); разметка `main.ts` получает минимальные классовые правки (обёртки-карточки, подписи состояний) без изменения id/структуры, на которую опираются тесты.
- Тесты: jsdom не измеряет внешний вид — добавляется точечный css-тест (токены определены, правил `transition/animation` нет, focus-visible стилизованы); остальные проверки — ручной просмотр трёх экранов.
- Риски только визуальные: откат = возврат одного файла style.css (+ классы в main.ts).
