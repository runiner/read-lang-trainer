# Spec Delta

## MODIFIED Requirements

### Requirement: База примеров размечена по уровням
Система SHALL хранить встроенную базу примеров; каждый пример относится ровно к одному из шести уровней: «гласные», «простые слоги», «слоги», «слова», «фразы», «текст». Каждый пример — текст для чтения вслух (кириллица). Уровень «текст» хранит произведения классических детских текстов, каждое с названием и автором.

#### Scenario: Пример на каждом уровне
- **WHEN** запрашиваются примеры любого из шести уровней
- **THEN** возвращается непустой набор примеров этого уровня

#### Scenario: Произведения уровня «текст»
- **WHEN** запрашивается список произведений уровня «текст»
- **THEN** возвращаются не менее двух произведений, у каждого есть название, автор и ненулевой текст

### Requirement: Подбор упражнений по уровню
Система SHALL формировать последовательность упражнений сессии только из примеров выбранного уровня сложности. Для уровня «текст» упражнениями являются части одного выбранного произведения в порядке их следования в тексте.

#### Scenario: Сессия уровня «гласные»
- **WHEN** запущена сессия уровня «гласные» размером 8
- **THEN** показаны 8 упражнений, каждый пример состоит из гласных букв уровня

#### Scenario: Сессия уровня «текст»
- **WHEN** запущена сессия уровня «текст» с выбранным произведением и размером N
- **THEN** показано N упражнений, которые по порядку воссоздают весь текст произведения

### Requirement: Размер сессии больше доступной базы
Если количество запрошенных упражнений превышает число уникальных примеров уровня, система SHALL повторять примеры до нужной длины. Это правило не применяется к уровню «текст»: там размер сессии задаёт число частей одного произведения, а не отбор из множества примеров.

#### Scenario: Недостаточно уникальных примеров
- **WHEN** запрошена сессия из 50 упражнений уровня с 20 уникальными примерами
- **THEN** сессия содержит 50 упражнений, примеры повторяются

#### Scenario: Уровень «текст» без повторов
- **WHEN** сессия уровня «текст» содержит N упражнений
- **THEN** каждое упражнение — следующая часть того же произведения, порядок соответствует тексту

## ADDED Requirements

### Requirement: Разбиение текста на части
Для уровня «текст» система SHALL разбивать выбранный произведение ровно на N частей по границам предложений, распределяя предложения между частями примерно поровну по числу символов. Предложение не разрывается между частями; объединение всех частей по порядку даёт исходный текст.

#### Scenario: Ровное разбиение
- **WHEN** текст из 12 предложений делится на 4 части
- **THEN** каждая часть содержит 3 предложения подряд, без пропусков и разрывов посреди предложения

#### Scenario: Частей больше, чем предложений
- **WHEN** размер сессии N превышает число предложений в произведении
- **THEN** система не создаёт пустых упражнений: сессия ограничивается числом предложений, и об этом сообщается настройками до старта
