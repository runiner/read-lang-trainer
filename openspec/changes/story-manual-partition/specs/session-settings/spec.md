# Spec Delta

## MODIFIED Requirements

### Requirement: Выбор произведения для уровня «текст»
При уровне «текст» окно настроек SHALL показывать список произведений (название и автор) и требовать выбор одного из них до старта сессии; количество упражнений определяется разметкой частей выбранного произведения, а не настройкой размера.

#### Scenario: Старт без выбора произведения
- **WHEN** уровень «текст» выбран, но произведение не выбрано и нажато «Начать»
- **THEN** сессия не стартует и система подсказывает выбрать произведение

#### Scenario: Размер больше числа предложений
- **WHEN** размер сессии 50, а в выбранном произведении 20 предложений
- **THEN** неактивное поле размера показывает 20 — число частей выбранного произведения; уменьшить или увеличить его нельзя

#### Scenario: Размер задаётся произведением
- **WHEN** взрослый выбрал произведение с 7 размеченными частями (например, ранее в поле стояло 50)
- **THEN** неактивное поле размера показывает 7 — число частей выбранного произведения; задать другое количество нельзя

### Requirement: Выбор размера сессии
Система SHALL позволять выбрать количество упражнений в сессии целым числом от 5 до 50 включительно для всех уровней, кроме «текст»; при выбранном уровне «текст» поле размера остаётся видимым, но становится неактивным (read-only) и показывает количество частей выбранного произведения.

#### Scenario: Выбор допустимого значения
- **WHEN** взрослый выбирает размер сессии 15 и подтверждает настройки
- **THEN** сессия стартует с 15 упражнениями

#### Scenario: Недопустимое значение
- **WHEN** взрослый пытается задать значение вне диапазона 5–50
- **THEN** система не принимает значение и подсказывает допустимый диапазон

#### Scenario: Уровень «текст» делает поле размера неактивным
- **WHEN** взрослый переключает уровень на «текст» и выбирает произведение
- **THEN** поле размера остаётся видимым, неактивным и содержит число частей этого произведения; при смене произведения значение обновляется; при возврате к другому уровню поле снова активно и редактируемо
