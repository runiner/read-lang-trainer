# Proposal

## Why

Автоматический сплит по пунктуации даёт куски, ровные по длине, но не всегда удобные для чтения ребёнку: граница может оторвать «— говорит» от реплики или разбить смысловую фразу. Взрослый/составитель текста видит разбиение лучше алгоритма. Переводим уровень «текст» на ручную разметку: части задаются переносом строки в самом тексте произведения, а количество упражнений определяется этими частями, а не настройкой размера.

## What Changes

- Тексты уровня «текст» хранятся уже размеченными: каждая строка (`\n`) — одна часть (упражнение). Пустые строки игнорируются.
- При выбранном уровне «текст» поле «Упражнений в сессии» не используется: размер сессии = число размеченных частей выбранного произведения; вместо поля показывается это число («N частей»).
- Автоматический сплит по знакам препинания удаляется из системы целиком (он применялся только к уровню «текст»): больше нет `split_sentences`/`story_parts` как источника границ; нет cap-подсказок «максимум N упражнений» и блокировки старта по размеру.
- Существующие басни пере-размечаются вручную по смысловым границам.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `exercise-content`: уровень «текст» получает части из ручной разметки строками вместо алгоритмического разбиения; требование «Разбиение текста на части» заменяется на «Части текста заданы разметкой»; правило повторов при переполнении явно не трогает «текст» (без изменений по сути, формулировка обновляется под новый источник размера).
- `session-settings`: при уровне «текст» размер сессии задаётся произведением (поле размера скрыто), выбор произведения обязателен как раньше; убирается валидация «size > maxParts».

## Impact

- `crates/core`: `Story.text` → `parts: &[&str]` (или текст + accessor по строкам); удаление `split_sentences`, `story_fragments`, `story_parts`, `sum_lens`, `nearest_cut`, DP-блока и связанных тестов; `Session::with_story` берёт части напрямую; `story_sentence_count` → число строк-частей.
- `crates/wasm`: сигнатура `create_session(level, size, seed, story_id)` сохраняется; для Text параметр size игнорируется (= число частей); `stories_json().maxParts` переименован-по смыслу в `parts`.
- `web/`: экран настроек — conditional скрытие поля размера при «текст», показ «N частей»; удаление hint-логики про максимум; обновление story.test/presentation-тестов; тексты басен в stories.rs перезаписываются построчно.
