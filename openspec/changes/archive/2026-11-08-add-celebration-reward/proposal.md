# Proposal

## Why

Ребёнку 5–7 лет нужен мгновенный эмоциональный отклик за хорошо прочитанное — без внешней похвалы усилие «читать вслух» не закрепляется. Взрослый, который и так слушает чтение, теперь может отметить успех одной кнопкой на экране статистики, и приложение устроит короткое празднование: конфетти, пляшущий щенок и заводная музыка.

## What Changes

- На экране статистики под кнопкой «В настройки» появляется вторая кнопка «Отлично!». Нажатие = оценка взрослого «упражнение/сессия пройдены хорошо» → запускается празднование.
- Празднование длится 10–15 секунд и состоит из: сыплющихся конфетти; пляшущего анимированного щенка (собственная рисовка-спрайт в стилизации «пёс в каске», без копирования персонажей «Щенячьего патруля»); бодрой музыки с короткими fade-in/fade-out (первоначально — синтез WebAudio, «robot dance»-вайб; допускает замену аудиофайлом).
- Любое действие (тап/клик/пробел) или истечение времени завершает празднование и возвращает экран статистики. Повторное нажатие «Отлично!» проигрывает его заново. Оценка НЕ сохраняется в историю сессий (в этом change).
- Исключение из правила «интерфейс статичен»: оформление экранов остаётся без анимаций, но празднование — явная, ограниченная по времени награда; обязателен учёт `prefers-reduced-motion` (конфетти/щенок заменяются статичной картинкой-наградой, музыка остаётся) и визуальное дублирование звука (экран самодостаточен без звука).

## Capabilities

### New Capabilities

- `celebration`: награда-празднование по оценке взрослого — состав, длительность, управление, доступность и границы (не влияет на статистику/историю).

### Modified Capabilities

- `session-stats`: экран статистики получает кнопку «Отлично!» под «В настройки»; её нажатие запускает празднование, экран после него возвращается без изменений данных.
- `ui-presentation`: требование «Статичность интерфейса» уточняется — запрет анимаций действует для оформления и обычных переходов, но не запрещает ограниченное празднование capability `celebration`.

## Impact

- `web/src/main.ts`: кнопка `#great` на экране статистики + оверлей празднования (`renderCelebration`).
- Новые модули: `web/src/celebration.ts` (конфетти canvas/CSS, скелет-анимация щенка), `web/src/music.ts` (WebAudio-секвенсор с fade-in/out). Анимации — только внутри оверлея.
- Ассеты: `web/public/puppy/` — спрайты (рисуются программно SVG/PNG, свой дизайн). Никаких npm-зависимостей (без canvas-библиотек).
- Тесты: jsdom не проигрывает анимации/WebAudio — проверяются DOM-контракты (кнопка, появление/закрытие оверлея, таймаут через fake timers, поведение reduced-motion); визуальное — ручной просмотр.
- Ядро (Rust) не меняется: оценка не попадает в SessionRecord.
