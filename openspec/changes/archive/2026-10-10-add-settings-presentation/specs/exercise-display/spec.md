# Spec Delta

## Purpose

Определяет, как текст упражнения выглядит для ребёнка: семейство шрифта и регистр букв, область их действия и сохранение выбора между запусками.

## ADDED Requirements

### Requirement: Регистр отображения текста
Система SHALL отображать текст упражнения в выбранном регистре: прописные — все буквы заглавные, строчные — как в базе примеров. Транслитерация применяется только к отображению; содержание примера и его длина в символах не изменяются.

#### Scenario: Слог в прописных
- **WHEN** регистр «прописные» и текущий пример «ма»
- **THEN** на экране показано «МА»

#### Scenario: Фраза со словами разного написания
- **WHEN** регистр «строчные» и текущий пример содержит слово с заглавной буквой
- **THEN** текст показывается без изменений

### Requirement: Область действия шрифта и регистра
Выбранные шрифт и регистр SHALL применяться ко всему тексту упражнений во всех режимах (экран упражнения, предпросмотр в настройках). Служебный интерфейс (подписи настроек, статистика) использует выбранный шрифт, но остаётся в обычном написании.

#### Scenario: Переход между упражнениями
- **WHEN** сессия идёт с регистром «прописные»
- **THEN** каждый следующий пример также показан прописными буквами

### Requirement: Значения по умолчанию
Система SHALL использовать по умолчанию первый из предложенных шрифтов и строчный регистр, если у пользователя нет сохранённого выбора.

#### Scenario: Первый запуск без сохранённых настроек
- **WHEN** приложение открыто впервые на устройстве
- **THEN** упражнения показываются строчными буквами шрифтом по умолчанию
