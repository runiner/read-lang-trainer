# Spec Delta

## MODIFIED Requirements

### Requirement: Выбор произведения для уровня «текст»
При уровне «текст» окно настроек SHALL показывать список произведений (название и автор) и требовать выбор одного из них до старта сессии; количество упражнений определяется разметкой частей выбранного произведения, а не настройкой размера. Список произведений SHALL быть полным при каждом открытии окна настроек, включая возврат из завершённой сессии без перезагрузки страницы.

#### Scenario: Старт без выбора произведения
- **WHEN** уровень «текст» выбран, но произведение не выбрано и нажато «Начать»
- **THEN** сессия не стартует и система подсказывает выбрать произведение

#### Scenario: Размер больше числа предложений
- **WHEN** размер сессии 50, а в выбранном произведении 20 предложений
- **THEN** окно настроек показывает, что произведение даст максимум 20 упражнений, и предлагает уменьшить размер или выбрать другой текст

#### Scenario: Размер задаётся произведением
- **WHEN** взрослый выбрал произведение с 7 размеченными частями
- **THEN** неактивное поле размера показывает 7, и запустить другое количество нельзя

#### Scenario: Вторая Text-сессия подряд
- **WHEN** после завершения сессии уровня «текст» взрослый вернулся в окно настроек и снова выбрал уровень «текст»
- **THEN** список произведений содержит все доступные произведения, новую сессию можно запустить без перезагрузки страницы
