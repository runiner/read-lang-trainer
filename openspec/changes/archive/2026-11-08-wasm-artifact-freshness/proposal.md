# Proposal

## Why

Контент упражнений запечён в wasm-артефакт (`include_str!`), и пользователь уже столкнулся с тем, что после правки `content/*.json` приложение показывало старые тексты: тесты на JSON зелёные, а браузер исполняет устаревший `web/pkg`. Сейчас свежесть держится только на доброй воле команд (`npm run dev` пересобирает wasm — хрупкое соглашение). Нужна проверяемая гарантия: артефакт, который отдаётся пользователю, всегда собран из текущих контентных документов.

## What Changes

- Вводится явное требование свежести: собранный wasm-артефакт (dev-сервер, прод-билд, деплой) обязан содержать ровно те упражнения, которые лежат в `content/levels.json` и `content/stories.json` на момент сборки.
- В контент добавляется встроенныйstamp версии: SHA-256 от байтов обоих JSON-документов, вычисляемый при сборке core; рантайм-экспортируемая функция `content_version()` возвращает его.
- Проверка соответствия выполняется автоматически: CI-шаг сравнивает `content_version()` из собранного pkg с контрольной суммой, посчитанной от файлов репозитория; расхождение валит сборку. Локально ту же проверку делает `npm --prefix web run test` (vitest-тест против pkg).
- Поведение пользователя не меняется: команды остаются теми же, но «старые тексты в браузере» превращаются из тихой ошибки сборки в явную красную CI/тест.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `exercise-content`: новое требование «Свежесть собранного контента» — собранный артефакт обязан совпадать с контентными документами, механизм — контент-stamp и автоматическая проверка; документы получают канонический способ идентификации версии.

## Impact

- `crates/core`: `content_data.rs` — const-вычисление SHA-256 от include_str! байтов (новая лёгкая зависимость `sha2` или ручной вариант — решает design), экспорт `content_version() -> &'static str`.
- `crates/wasm`: экспорт `content_version()` через wasm-bindgen; фасад `web/src/wasm.ts` пробрасывает функцию.
- `.github/workflows/deploy.yml`: шаг сверки stamp после build:wasm до upload-pages-artifact.
- `web/`: vitest-тест pkg-vs-файлы; скрипты dev/test/build уже пересобирают wasm (сделано ранее) — остаются как есть.
- Существующие тесты/поведение подбора не затрагиваются.
