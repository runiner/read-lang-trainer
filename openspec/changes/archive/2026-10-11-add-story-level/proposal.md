# Proposal

## Why

После фраз ребёнку нужно читать связные истории — это главный мотивационный шаг: «я прочитал целую сказку». Текущий верхний уровень «фразы» даёт только отдельные предложения. Добавляем уровень «текст»: классические детские тексты (басни Крылова, рассказы) делятся на ровно N частей по количеству упражнений и показываются последовательно, поэтому за сессию ребёнок прочитает произведение целиком.

## What Changes

- В базе примеров появляется шестой уровень «текст»: набор из нескольких произведений классиков (Крылов, Барто, Мамин-Сибиряк и др.), каждое — цельный текст с названием и автором.
- При выборе уровня «текст» в окне настроек дополнительно выбирается конкретное произведение из списка (название + автор).
- Выбранный текст разбивается на ровно N частей по границам предложений, примерно равных по длине; предложение никогда не разрывается; части показываются строго по порядку — от начала до конца произведения.
- Уровень «текст» не использует перемешивание и повторы: порядок = порядок чтения истории.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `exercise-content`: база получает шестой уровень «текст» с произведениями и правило разбиения выбранного текста на N упорядоченных частей (вместо перемешивания/повторов для этого уровня).
- `session-settings`: шесть уровней вместо пяти; при уровне «текст» появляется выбор произведения; размер сессии по-прежнему 5–50 и равен числу частей.

## Impact

- `crates/core`: enum `Level` +вариант `Text`; новый модуль `stories.rs` (произведения как статические тексты); `session_plan` для Text идёт по новому пути (сплит по предложениям, без RNG); `SessionRecord.level` получает значение `"text"`.
- `crates/wasm`: `create_session` принимает id произведения (доп. параметр или составной level-строкой — решает design).
- `web/`: select уровня получает шестую опцию; conditional select «Произведение»; предпросмотр первой части.
- Контент: 6–10 текстов по ~400–1500 символов; объём wasm вырастет на десятки КБ — приемлемо.
