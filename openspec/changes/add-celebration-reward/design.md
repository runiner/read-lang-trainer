# Design

## Context

Экран статистики рендерится `renderStats()` в [main.ts](../../web/src/main.ts) (кнопка `#again` «В настройки»). Правило ui-presentation «Статичность интерфейса» сейчас запрещает transition/animation глобально и защищено тестом [style.test.ts](../../web/src/style.test.ts) (grep `transition:`/`animation:`/`@keyframes` в style.css) — дельта этого change превращает запрет в «кроме оверлея празднования», тест-защитник надо перенастроить согласованно. Пользовательские решения: щенок — собственная рисовка (стилизация, не копипаст PAW), музыка — синтез WebAudio. Конвенция проекта: без новых npm-зависимостей ради нескольких строк (ponytail).

## Goals / Non-Goals

**Goals:**
- Один self-contained модуль празднования с DOM-контрактом, тестируемым в jsdom без реальных анимаций.
- Нулевые внешние ассеты кроме нарисованных SVG-кадров щенка; офлайн сохраняется.
- Уважение prefers-reduced-motion и «звук имеет визуальный эквивалент» из AGENTS.md.

**Non-Goals:**
- Сохранение оценок в историю/статистику, накопление «звёздочек», разные награды по уровням.
- Готовые библиотеки конфетти/lottie, аудиофайлы (допускается будущий refinement на файл).
- Точные хореографии: 2–3 кадра покадровой анимации достаточно.

## Decisions

1. **Архитектура оверлея.** `celebration.ts`: `startCelebration(root: HTMLElement, opts): { stop(): void }` — создаёт `<div id="celebration" class="celebration-overlay">` поверх всего (position fixed, z-index выше кнопок), внутри: canvas `.confetti` (2D, ~80 частиц, requestAnimationFrame, физика падения+дрейф), `<img id="puppy">` со сменой src по кадрам (setInterval 150мс, 3 кадра: up/left/right поза), надпись «Молодец!». По истечении `durationMs` (константа 12_000, середина диапазона 10–15) или первому pointerdown/keydown → `stop()`: снять слушатели, cancelAnimationFrame, остановить музыку, удалить оверлей. Всё поведение — классы/id, jsdom тестирует структуру и вызовы.
2. **Музыка.** `music.ts`: WebAudio-секвенсор ~120 BPM, квадратная волна бас + арпеджио синт-«робот данс»; gain-огибающие fade-in 300ms и fade-out последние 1.5s. API `playCheerMusic(ctx?): {stop()}`. AudioContext создаётся по клику «Отлично!» (user gesture — автоплей-политики браузеров удовлетворён). Если WebAudio недоступен — тишина, спеке это не противоречит (визуальный эквивалент есть).
3. **Капиталить таймеры через инъекцию.** `startCelebration(root, { durationMs, now, schedule })` — дефолты реальные; тесты подменяют `schedule` fake-таймерами vitest (`vi.useFakeTimers`). Иначе гонять 12 секунд в тесте нельзя.
4. **Reduced motion.** `matchMedia('(prefers-reduced-motion: reduce)').matches` на старте: вместо rAF-конфетти и смены кадров — статичный PNG-щенок + CSS-класс `.static` (без keyframes), таймер и музыка те же. Тест мок-ит matchMedia.
5. **Спрайты щенка.** Три SVG-кадра рисуются вручную (жёлтый пёс в красной каске — цветовая стилизация «спасателей», морда/уши уникальные силуэты, никаких узнаваемых имён/логотипов) + один статичный вариант; лежат `web/public/puppy/frame-{1,2,3}.svg`. Альтернатива процедурная canvas-собака отвергнута: дороже отладкой.
6. **Кнопка.** В `renderStats()` после `#again`: `<button id="great" class="big great-btn">Отлично!</button>` (вторичный стиль: акцент-обводка, не закрашенная — акцентная заливка остаётся одной главной кнопке по правилу токенов). Обработчик: `startCelebration(document.body, …)`; повторный клик после завершения работает (функция идемпотентна к отсутствию активного оверлея).
7. **Развязка с защитником стиля.** `style.test.ts` меняет правило: `transition:/animation:/@keyframes` разрешены только в блоках селекторов, начинающихся с `.celebration-overlay`/`#celebration`; базовые экраны проверяются как раньше. Спецификация ui-presentation обновлена дельтой этого change.

## Risks / Trade-offs

- [WebAudio-синтез звучит «чиптюнно», беднее mp3] → принято; замена файлом — отдельный маленький change (спека про это нейтральна к источнику).
- [12 секунд конфетти на слабом телефоне = дёрганье] → 80 частиц целиться вниз по FPS? нет: константа выбрана с запасом; при жалуемой нагрузке — сокращаем число частиц (одна переменная).
- [Рисованный щенок «немного похожий» всё равно субъективен] → юридически чисто: оригинальная форма; эстетическую правку делает взрослый после первого занятия.
- [jsdom не ловит регрессии реального рендера] → ручной просмотр 3.х задач; автоматика только структурная.

## Open Questions

- Отметки «Отлично!» в истории (колонка звёзд) — следующий change при желании.
- Разные персонажи наград (щенок/котёнок) — не планируем.
