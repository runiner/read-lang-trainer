# Spec Delta

## MODIFIED Requirements

### Requirement: Экран статистики по завершении
Система SHALL показать статистику завершённой сессии: дату, уровень сложности, количество выполненных упражнений, длительность сессии и скорость чтения. Под кнопкой «В настройки» экран SHALL содержать кнопку «Отлично!», запуск и поведение которой определены capability `celebration`.

#### Scenario: Завершение сессии из 12 упражнений
- **WHEN** сессия из 12 упражнений завершена
- **THEN** экран статистики показывает 12 выполненных упражнений, уровень сессии, дату, длительность и скорость чтения

#### Scenario: Кнопка «Отлично!» на месте
- **WHEN** показан экран статистики
- **THEN** под «В настройки» видна кнопка «Отлично!»
