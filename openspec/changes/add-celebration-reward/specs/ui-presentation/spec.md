# Spec Delta

## MODIFIED Requirements

### Requirement: Статичность интерфейса
Система SHALL мгновенно переключать экраны и не использовать анимаций или переходов (transition/animation) в оформлении; изменение состояния элемента заметно мгновенной сменой цветов/границ. Ограничение не распространяется на празднование capability `celebration`: оно — единственное место, где движение допустимо, и только пока активно.

#### Scenario: Смена упражнения без перехода
- **WHEN** ребёнок перешёл к следующему упражнению
- **THEN** новый текст появляется мгновенно, без затухания или сдвига

#### Scenario: Празднование — разрешённое исключение
- **WHEN** активно празднование
- **THEN** движущиеся элементы появляются только внутри его оверлея, а оформление базового экрана остаётся статичным
