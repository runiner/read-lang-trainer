# Proposal

## Why

Два дефекта после последних циклов: (1) при возврате из завершённой сессии на экран настроек список «Произведение» становится пустым — взрослый не может второй раз запустить уровень «текст», обходится только перезагрузкой страницы; (2) скорость чтения в символах/минуту — метрика неудобная для взрослого: в русской речи слова разные по длине, ориентир «слов в минуту» привычен из методичек обучения чтению.

## What Changes

- Исправляется баг списка произведений: после завершения сессии и возврата в настройки select «Произведение» снова содержит полный список (placeholder + все произведения), выбор уровня «текст» работает повторно без перезагрузки. Поведение проверяется сквозным тестом «две Text-сессии подряд».
- Скорость чтения считается в **словах в минуту**: слово = последовательность букв (кириллица с ударными знаками внутри); разделители — пробелы, переносы и пунктуация; тире/кавычки сами по себе словами не являются. Пример: «мама мыла, — говорит, — раму» = 4 слова.
- Формат записи статистики меняется: `chars_per_min` → `words_per_min`. Уже сохранённые старые записи НЕ мигрируются: в истории они отображаются с прочерком вместо скорости.
- Экран статистики и история показывают «слов/мин»; README обновляет описание метрики.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `session-settings`: требование «Выбор произведения для уровня «текст»» дополняется гарантией повторного использования списка после возврата из сессии (баг-фикс как проверяемое поведение).
- `session-stats`: требование «Скорость чтения» пересчитывается в слова/минуту с определением слова; «Сохранение истории» фиксирует новую схему поля и поведение со старыми записями.

## Impact

- `web/src/main.ts`: список произведений после возврата из сессии пуст, потому что populate защищён условием `if (stories.length === 0)` и больше не выполняется, а `renderSettings()` пересоздаёт select без опций — фикс: опции проставляются при каждом рендере окна настроек; текст статистики «слов/мин».
- `crates/core`: подсчёт слов (`total_words`) вместо символов в `SessionRecord`; `words_per_min: Option<u32>`; юнит-тесты определения слова (пунктуация, ударения, «по-братски» = 1 слово).
- `web/src/wasm.ts`/`history.ts`: тип записи; адаптер истории терпит записи без нового поля (прочерок).
- Локальные данные пользователей: старые localStorage-записи остаются, скорость в них не показывается.
