# AGENTS.md — rus-lang-trainer

Детское веб-приложение для обучения чтению русских слогов. Rust → WebAssembly, фронтенд на TypeScript + Vite.

## Как мы разрабатываем: OpenSpec (spec-driven)

Никакого кода без принятой спецификации. Порядок для любой фичи/изменения:

1. **Propose** — скилл `openspec-propose`: создаёт `openspec/changes/<change-id>/` с `proposal.md`, `design.md`, `specs/**/spec.md` (дельта-спека), `tasks.md`. Только планирование, без кода.
2. **Review** — человек читает артефакты и правит формулировки. Это обязательный шаг: спека дешевле кода.
3. **Apply** — скилл `openspec-apply-change`: реализация по `tasks.md`, задачи отмечаются `[x]` по мере выполнения.
4. **Archive** — скилл `openspec-archive-change`: после завершения дельта-спеки сливаются в `openspec/specs/`, change переезжает в `openspec/changes/archive/`.

Мелкие правки (опечатка в доке, косметика) могут идти мимо цикла; всё, что меняет поведение приложения — через change. CLI: `npx @fission-ai/openspec <command>` (`list`, `validate <change>`, `archive <change>`).

Скиллы лежат в `.agents/skills/` (открыть можно через `read`).

## Ponytail (режим ленивого сеньора)

Скилл `ponytail` активен по умолчанию на всех кодинг-задачах: минимальное полное изменение, никаких абстракций «на будущее», никаких новых зависимостей ради нескольких строк. Не сокращать: валидацию на границах доверия, обработку ошибок, безопасность, доступность (a11y критична — приложение для детей). Ответ заканчивать строкой о том, что пропущено/не проверено. Команды-скиллы: `ponytail-review`, `ponytail-audit`, `ponytail-debt` (собирает комментарии `shortcut:`).

## Стек и структура

- `crates/core` — чистая Rust-логика (складовые syllables, правила озвончения, прогресс). Без wasm-bindgen внутри — тестируется обычным `cargo test`.
- `crates/wasm` — тонкая прослойка `wasm-bindgen` над core.
- `web/` — Vite + TypeScript UI (рендер, звук, ввод ребёнка). Вызовы в wasm только через типизированный фасад `web/src/wasm.ts`.
- Артефакт wasm-pack: `web/pkg/` (в git не попадает).

```
cargo test -p rus-core              # быстрая проверка логики
wasm-pack build crates/wasm -t web  # собрать wasm для web/
npm --prefix web run dev            # дев-сервер
npm --prefix web run test           # ui-тесты (vitest + jsdom, если подключим)
```

## Что важно для этого продукта

- Целевая аудитория: дети ~5–7 лет, только начинают читать по-русски. Крупная типографика, минимум текста на экране, отклик на любое действие.
- Все артефакты OpenSpec (спеки, таски) пишем по-русски.
- Большие фикстуры (аудио, картинки) — отдельными файлами, не инлайнить в код.
- Доступность: клавиатурная навигация, `lang="ru"`, контраст, никакого звука без визуального дублирования.

## Кодекс изменений

- Один change = одна цель; scope creep оформляется отдельным change.
- Перед коммитом: затронутые `cargo test` зелёные; если менялась спека — `npx @fission-ai/openspec validate <change>`.
- Конвенции языка и стиля — за cargo/clippy/rustfmt и tsc; спорные места решаются в design.md changes, а не молча.
